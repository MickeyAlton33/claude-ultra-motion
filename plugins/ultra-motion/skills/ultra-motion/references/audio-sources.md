# Free music & SFX — sources and licence rules

Ask the user to download files themselves (Claude doesn't log in to sites or accept terms for them), drop them in
`assets/audio/`, then log each one in `credits.md` before it goes into the composition.

## Licence preference (best first)
1. **CC0 / public domain** — no conditions. Still log it.
2. **Royalty-free, no attribution** (e.g. Pixabay Content License, Mixkit) — read the restrictions
   (usually: no reselling the file alone, no trademark use).
3. **CC BY** — fine, but the credit line must appear where the video is published (description or end card).
4. **Never for commercial or client work:** any **NC** (non-commercial) licence.
   Avoid **ND** (no-derivatives) too: cutting, looping and mixing under VO is arguably a derivative.
5. **Unknown licence = don't use it.**

## Voice
- Kokoro-82M (Apache-2.0) VO generated by `tts.py` is yours to use commercially; credit is courtesy, not required.
- Never clone a real person's voice.

## Mixing rules
- Music bed under VO: `data-volume` 0.08–0.126 (−22 to −18 dB), default 0.1 (−20 dB).
- Music in VO-free stretches can rise to 0.25–0.35; ramp with `data-fade-in` / `data-fade-out` (≥ 0.3 s).
- SFX: short (< 1 s), synced to the visual hit (± 1 frame), 0.2–0.5 volume, never on every cut.
- Final loudness is set by `deliver.sh` (−14 LUFS, −1.5 dBTP); don't normalize stems by ear.
